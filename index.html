Air comes in uneven. It leaves the plenum the same.

A plenum is the box between a fan and the rooms it feeds: the fan pushes one loud, lopsided stream, and the chamber turns it into even pressure at every outlet. This chain is built the same way — one algorithm, one reward, the same pressure on every card, and no privileged inlet.

01What it is

One part, one job, no exceptions.

Plenum is a proof-of-work coin mined with KawPoW, the memory-hard algorithm that keeps a general-purpose graphics card the efficient machine for the job. The rules are public, the emission is arithmetic, and nothing in the protocol pays an address that is not a miner.

There is no company behind it, no foundation wallet, no presale, no governance token and no way for a first block to be cheaper than the ten-millionth. What exists today is a fixed specification, a set of documents, and a Windows wallet that holds keys. What does not exist is a running network — and every page here says so where it matters.

If you are looking for a chain to mine right now, this is not one. There is no node to connect to, no pool, and no explorer with blocks in it. That is the current state, not a marketing gap.

86,400 seconds divide by 240 exactly 360 times, so a day is 360 blocks and an era of 288,000 blocks is 800 days. The first era pays 360 × 52 = 18,720 PLNM a day, 14,976,000 over its length. Each later era pays half per block, so the whole series is twice the first era: 29,952,000 PLNM, and it closes exactly.

No premine, no presale, no development cut, no fee on a mined block, no treasury address. A block pays its finder and nobody else.

03Mining

KawPoW, because the card you already own is the point.

KawPoW keeps a memory-hard DAG and adds a math sequence regenerated every period plus wider memory reads, so an ASIC does not pay for itself and a current GPU does. One epoch is 7,500 blocks — about 31 days at this interval — and the DAG grows by roughly 8 MB per epoch from about 1.07 GB at epoch zero. Size the card at 8 GB of video memory, not 4.

A miner will run this, once there is something to point it at:

t-rex -a kawpow \
  -o stratum+tcp://<pool-host>:<port> \
  -u <your Z address> -p x

There is no pool host today. The line is printed because the shape of the work should be known before the work exists, not because it will connect.

P2P listens on 19007, RPC on 19008, and addresses begin with Z. These are commitments in the specification, not observed facts about a live network.

05Straight answers

The four questions, answered before they are asked.

Is there a premine?

No. Block one pays whoever finds block one, exactly like the last block will. There is no address the protocol pays on its own.

Is there a development fee?

No. There is no treasury, no foundation, no coin set aside for a team. Whoever wants coins mines them or buys them from someone who did.

When is it listed?

Not scheduled and not promised. A listing is another party's decision; it is not part of this design and no page here will imply otherwise.

Can I mine today?

No. There is no network to mine on yet. Pointing a rig at an unreleased chain would burn power to produce nothing.
