One build, one hash, no installer tricks.

The Windows wallet is published as a plain zip. Nothing is bundled, nothing downloads anything else, and the file is not code-signed — so check the hash before you run it. Linux and macOS builds do not exist yet.

A download page that offers three operating systems and delivers one is normal here: this is a v0.1.0 released by one maintainer, not a product launch.

02Before you run

What the build does and does not do.

  • It generates, stores and prints keys, and derives Z addresses from them.
  • It does not sync a chain, because there is no chain to sync.
  • It does not connect to any host on start, and it has no update mechanism.
  • It is not signed with a certificate, so Windows will warn on first run.

Every one of those points is repeated on the Windows page next to the file itself, together with the size, the hash and a command that checks the hash on your machine.
