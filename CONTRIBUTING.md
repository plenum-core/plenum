# Contributing

Useful, in this order:

1. **Review the specification.** If a number is wrong, contradictory or unreachable, say so in an issue with the arithmetic attached.
2. **Port the wallet.** A Linux or macOS build of the same key handling is the most useful missing piece.
3. **Write a tool.** A DAG size calculator, a KawPoW benchmark table, a hash verifier for the release page.
4. **Check the documents.** Typos, dead links, claims that do not match the code.

Not wanted:

- Price talk, listing requests, or "when moon" issues.
- Telegram, Discord or "community" groups started in the project's name. There are no official channels, so any group claiming to be one is not.
- Pull requests that add tracking, analytics, external fonts or third-party scripts to the site. It is static on purpose.

## Style

Plain Markdown, tables for numbers, no marketing adjectives. If a sentence would look odd in a datasheet, rewrite it.
