04API

What an indexer would answer, and what this one answers.

The shape of a future response, fixed now so that clients can be written against it:

GET /api/status
{
  "height": 0,
  "supply": 0,
  "peers": 0,
  "error": "no chain"
}

That is the entire API surface today. It is documented in docs/API.md so the emptiness is a contract, not an accident.
